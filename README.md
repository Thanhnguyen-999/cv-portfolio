# CV Portfolio

Website sơ yếu lý lịch cá nhân phong cách vCard hiện đại — dùng để xin việc.

## Xem demo

Mở file `index.html` trên trình duyệt, hoặc bật GitHub Pages:
**Settings → Pages → Deploy from a branch → main → /** — web sẽ chạy ở
`https://Thanhnguyen-999.github.io/cv-portfolio/`

## Cấu trúc

```
├── index.html          # Toàn bộ website (1 file duy nhất)
├── assets/
│   └── avatar.svg      # Ảnh đại diện (placeholder — thay bằng ảnh thật)
└── README.md
```

## Tùy chỉnh (thay dữ liệu mẫu)

> ⚠️ Toàn bộ nội dung hiện tại là **dữ liệu mẫu** — hãy thay bằng thông tin thật:

1. **Ảnh đại diện**: thay file `assets/avatar.svg` bằng ảnh của bạn
   (đặt tên `avatar.jpg`/`avatar.png` rồi sửa đường dẫn trong `index.html`).
2. **Thông tin cá nhân**: tìm `Nguyễn Minh An` trong `index.html` để thay tên,
   chức danh, email, phone, địa chỉ, ngày sinh.
3. **Kinh nghiệm / Học vấn / Dự án / Kỹ năng / Blog**: sửa trực tiếp các
   section tương ứng trong `index.html` (có comment đánh dấu từng phần).
4. **Màu sắc**: tông vàng gold `#ffdb70` — tìm và thay mã màu này nếu muốn
   đổi accent.

## Công nghệ

- HTML + CSS + JavaScript thuần (không framework, không build step)
- Responsive đầy đủ (desktop / mobile)
